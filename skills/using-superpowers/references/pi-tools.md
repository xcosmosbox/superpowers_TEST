## pi-subagents包
- **归属**：子代理系统 / 子代理包

**摘要**（可编辑）
提供子代理工具的可选伴侣包。

**详述**（可编辑）
pi-subagents 是 Pi 平台的可选伴侣包，需单独安装。它提供 subagent 工具，支持多种子代理工作流，包括单一代理任务、链式调用、并行执行、异步操作、分叉上下文处理以及恢复和状态监控等。

## 工具可用性说明
- **归属**：环境与配置 / 环境配置

**摘要**（可编辑）
关于核心环境缺少某工具时的备选方案和说明。

**详述**（可编辑）
Pi 核心环境默认不提供标准的子代理工具或任务列表工具。子代理功能可通过安装可选的 pi-subagents 包获得，该包提供的 subagent 工具支持多种工作流。若未安装任何子代理工具，系统不得虚构 Task 调用，而应在当前会话中顺序执行任务，或明确告知用户可选子代理能力未安装。对于任务跟踪，优先使用已安装的待办事项或任务扩展提供的工具；若无此类扩展，则采用 Superpowers 计划文件、Markdown 检查清单或仓库本地的 TODO.md 文件作为替代方案。

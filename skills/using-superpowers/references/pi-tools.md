- **归属**：子代理与并发 / 子代理工具

**摘要**（可编辑）

## 工具可用性说明
- **归属**：工具与技能框架 / 工具可用性

**摘要**（可编辑）
关于核心环境缺少某工具时的备选方案和说明

**详述**（可编辑）
在Pi核心环境中，默认不提供标准子代理工具或任务列表工具。子代理功能可通过安装可选的pi-subagents包获得，该包提供的subagent工具支持多种工作流。若未安装任何子代理工具，系统不得虚构Task调用，而应在当前会话中顺序执行任务，或明确告知用户可选子代理能力未安装。对于任务跟踪，优先使用已安装的待办事项或任务扩展提供的工具；若无此类扩展，则采用Superpowers计划文件、Markdown检查清单或仓库本地的TODO.md文件作为替代方案。

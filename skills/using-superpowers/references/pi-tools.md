- **归属**：代理编排与智能工作流 / 子代理与技能

**摘要**（可编辑）
提供子代理工具的可选伴侣包

**详述**（可编辑）
pi-subagents 是 Pi 平台的可选伴侣包，需要单独安装。它提供 subagent 工具，支持多种子代理工作流，包括单一代理任务、链式调用、并行执行、异步操作、分叉上下文处理以及恢复和状态监控等功能，为复杂代理编排场景提供了强大的基础能力。

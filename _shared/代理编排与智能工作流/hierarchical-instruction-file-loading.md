## 层次化指令文件加载机制
- **归属**：代理编排与智能工作流 / 指令加载

**摘要**（可编辑）
按优先级从全局、项目到子目录逐层合并指令文件内容的加载机制

**详述**（可编辑）
在Codex CLI和Gemini CLI等工具中，指令文件分别以AGENTS.md和GEMINI.md命名，并采用层次化加载机制。全局配置文件位于用户主目录下（如~/.codex/AGENTS.md或~/.gemini/GEMINI.md），会被首先加载；项目级配置文件在当前工作区目录及其所有祖先目录中依次发现并加载；此外，当工具访问某个子目录中的文件时，该子目录下的指令文件也会被加载。这种层次化方式确保在不同层级均可提供指令，最终指令是各层级指令的组合。

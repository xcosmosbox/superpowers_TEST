## 预定义子代理类型
- **归属**：子代理管理 / 代理类型

**摘要**（可编辑）
平台内置或特定用途的子代理类型定义。

**详述**（可编辑）
平台预定义了一系列子代理类型，以满足不同任务场景的需求。在 subagent-driven-development 流程中，会生成审查子代理和实现子代理：审查子代理专门审查实现子代理提交的代码变更，返回审查报告后即可关闭，因为其任务完成且无需保持状态；实现子代理负责根据任务要求编写或修改代码，当审查不通过时，修复循环会继续使用同一个实现子代理，因此必须保持其打开直到审查通过再调用 close_agent 关闭，但如果工具无法向原有子代理发送消息，则每次修复轮次会以全新的实现子代理启动，并传递任务摘要、报告文件和发现。Gemini CLI 还内置了多种子代理：generalist 用于处理通用任务，可通过 invoke_agent 工具以 agent_name: "generalist" 调用，或在聊天中使用 @generalist 语法快速使用；cli_help 专门提供命令行帮助和指导；codebase_investigator 用于深入分析代码库，理解代码结构和依赖关系，辅助开发任务；browser_agent 用于控制浏览器进行自动化操作，但仅在启用浏览器工具功能时可用。
